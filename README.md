# Build for Andhra — Website

A responsive, static landing page for Build for Andhra. Built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages without a build step.

## Deploy to GitHub Pages

1. Create a public repository named **`buildforandhra.github.io`** under the **`buildforandhra` GitHub account or organization**.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root, not inside another nested folder.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **`main`** and folder **`/ (root)`**, then save.
6. Wait for the Pages deployment to complete. The expected URL is `https://buildforandhra.github.io/`.

If `buildforandhra` is not an organization/account you control, the GitHub Pages URL must match the actual account or organization name.

## Before launch

- Confirm that the `buildforandhra` account/organization exists and you have admin access.
- Update the GitHub links in `index.html` if repository names differ.
- Add the final approved logo and brand assets if you have official versions.
- Add a `LICENSE` file after choosing a license for this website. Do not assume that a license for the website automatically licenses community projects.
- Check all content, accessibility, mobile layout, and links before announcing the site.
- This is an independent community initiative and is not presented as an official government website.

## Local preview

Open `index.html` in a browser. No package installation or build command is required.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `assets/logo.svg` — original placeholder brand mark
- `assets/favicon.svg` — browser icon
